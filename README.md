Pokémon Card e
=========

This is a disassembly of the e-Reader cards released for Pokémon Ruby and Sapphire. Currently, it includes the English release of the Pokémon Battle e series, and the Eon Ticket.

This version of the disassembly has been agressively altered to suit FexCollects preferences/needs. It should build cleanly on linux from a clean checkout with `cd src && make generate && make -j8 verify`
